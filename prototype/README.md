# Leopold Museum · Website-Prototyp (Route 1 „Annäherung“)

Klickbarer Prototyp – Desktop und Mobile. Statische Seiten, kein Build nötig.

## Auf GitHub Pages veröffentlichen
1. Neues Repository anlegen und den gesamten Inhalt dieses Ordners hochladen (index.html liegt im Wurzelverzeichnis).
2. Settings → Pages → „Deploy from a branch“, Branch `main`, Ordner `/ (root)`.
3. Nach ein bis zwei Minuten ist der Prototyp unter der angezeigten Adresse erreichbar.

- `index.html` leitet auf `startseite.html` weiter.
- `praesentation.html` zeigt die Mobile-Ansicht im Gerätrahmen (für den Desktop).
- Demo-Daten: simuliertes Datum Mittwoch, 7. Oktober 2026, Programm und Videos sind Beispiele bzw. Platzhalter.
